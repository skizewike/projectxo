# Посредник «Еда по фото»

Маленький сервер на Cloudflare Workers (бесплатный тариф). Приложение шлёт ему фото, он добавляет общий ключ Google Gemini и пересылает запрос. Ключ лежит только здесь, в приложение не зашит. Фото и ответы не сохраняются, в хранилище только счётчики запросов.

Защита: только запросы вида `generateContent` к четырём разрешённым моделям; тело до 3 МБ; 15 запросов в сутки на установку приложения и 300 в сутки на всех (меняется в `wrangler.toml`). Общий лимит держите ниже дневного лимита вашего бесплатного ключа.

## Развернуть (один раз, около 10 минут)

Нужны: аккаунт Cloudflare (бесплатный, карта не нужна), Node.js и бесплатный ключ Google AI Studio (aistudio.google.com/apikey).

Команды выполняйте в этой папке.

1. Установить зависимости и войти в Cloudflare (откроется браузер):
   ```bash
   npm install
   npx wrangler login
   ```
2. Проверить код:
   ```bash
   npm test
   ```
3. Создать хранилище счётчиков и вписать его `id` в `wrangler.toml` вместо `ЗАМЕНИТЕ_НА_ID_ИЗ_КОМАНДЫ`:
   ```bash
   npx wrangler kv namespace create COUNTERS
   ```
4. Положить ключ Google в секрет (команда спросит значение, в файлы оно не попадает):
   ```bash
   npx wrangler secret put GEMINI_API_KEY
   ```
5. Выложить:
   ```bash
   npx wrangler deploy
   ```
   В конце будет адрес вида `https://xo-food-proxy.ИМЯ.workers.dev`. Проверка: откройте `адрес/health`, должно быть `{"ok":true}`.
6. Вписать адрес в приложение: в `app/gradle.properties` строка `foodAiProxyUrl=https://xo-food-proxy.ИМЯ.workers.dev`, затем собрать приложение заново.

## Ограничения бесплатного тарифа

- Cloudflare KV на бесплатном тарифе допускает около 1000 записей в сутки, а каждый запрос делает две. Поэтому примерно 500 распознаваний в сутки на всех; `GLOBAL_DAILY` не ставьте выше.
- Лимит ключа Google тоже общий. Когда он кончается, приложение показывает «лимит на сегодня закончился», а пользователь может вставить свой ключ в настройках.
- Счётчик по установке обходится переустановкой приложения. Это терпимо: общий лимит защищает ключ в любом случае.
