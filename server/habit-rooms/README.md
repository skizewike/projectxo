# Сервер комнат «Привычки вместе»

Маленький сервер на Cloudflare Workers с базой D1 (бесплатный тариф, карта не нужна). Через него двое друзей на разных телефонах видят отметки друг друга в общей привычке. Аккаунтов нет: человек получает случайный номер и секрет, когда создаёт комнату или входит по коду.

Что хранится: название привычки, расписание, псевдонимы и дни, когда каждый отметил. Больше ничего: ни имён, ни почты, ни телефона. Секрет хранится только как хеш. Адрес человека нигде не хранится, в счётчиках попыток лежит только его хеш и стирается через сутки.

## Правила

- В комнате двое (`MAX_MEMBERS` в `wrangler.toml`).
- Код приглашения: 6 знаков, живёт 7 дней, подходит один раз.
- Перебор кодов: не больше 20 попыток в час с одного адреса. Комнат с одного адреса не больше 10 в сутки, отметок на участника 400 в сутки.
- Отметка принимается за последние 14 дней и на сегодня (с запасом на часовые пояса).
- Комната, где никто не отмечался 90 дней, удаляется сама (раз в сутки в 03:00 UTC).
- Выход из привычки стирает отметки человека; последний вышедший удаляет комнату.

## Развернуть (один раз, около 5 минут)

Нужны Node.js и вход в Cloudflare (`npx wrangler login`, откроется браузер). Команды выполняйте в этой папке.

1. Установить зависимости и проверить код:
   ```bash
   npm install
   npm test
   ```
2. Создать базу и вписать её `database_id` в `wrangler.toml` (сейчас там id, созданный 2026-11-11 на аккаунте владельца; если базу создаёте заново, замените):
   ```bash
   npx wrangler d1 create xo-habit-rooms
   ```
3. Создать таблицы в настоящей базе:
   ```bash
   npx wrangler d1 execute xo-habit-rooms --remote --file=schema.sql
   ```
4. Выложить:
   ```bash
   npx wrangler deploy
   ```
   В конце будет адрес `https://xo-habit-rooms.ИМЯ.workers.dev`. Проверка: откройте `адрес/health`, должно быть `{"ok":true}`.
5. Адрес должен совпадать со строкой `sharedRoomsUrl` в `app/gradle.properties`. Если он другой, поправьте строку и соберите приложение заново.

Пока сервер не выложен, раздел «Вместе» в приложении скрыт: оно само проверяет `/health` и показывает раздел, только если сервер отвечает.

## Проверка на своём компьютере

```bash
npx wrangler d1 execute xo-habit-rooms --local --file=schema.sql
npx wrangler dev --local --port 8787
```

Эмулятору адрес `http://localhost:8787` отдаёт команда `adb reverse tcp:8787 tcp:8787`. Приложению для открытого адреса `http://` нужен временный файл `network_security_config` только для отладочной сборки; в выпуск он не входит.

## Протокол

| Запрос | Что делает |
|---|---|
| `GET /health` | `{"ok":true}` |
| `POST /v1/rooms` `{title, freqMask, nick}` | создать комнату; ответ: `roomId`, `memberId`, `secret`, `code`, `codeExpires` |
| `POST /v1/join` `{code, nick}` | войти по коду; ответ: `roomId`, `memberId`, `secret`, `title`, `freqMask`, `members` |
| `GET /v1/rooms/{id}` | участники и отметки за 60 дней |
| `PUT /v1/rooms/{id}/marks` `{day, value}` | поставить (1) или снять (0) свою отметку за день `yyyy-MM-dd` |
| `POST /v1/rooms/{id}/code` | новый код, если в комнате есть место |
| `DELETE /v1/rooms/{id}/me` | выйти и стереть свои отметки |

Всё, кроме создания и входа, требует заголовков `x-member-id` и `x-secret`.

## Лимиты бесплатного тарифа

D1 даёт около 100 000 записанных строк и 5 миллионов прочитанных в сутки. Одна отметка — одна запись, одно обновление экрана — несколько чтений. Для сотен пар друзей хватает с большим запасом.
