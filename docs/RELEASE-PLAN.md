## Перед выдачей обязательно

- `applicationId`: сейчас `com.projectxo.app`. Если сборка пойдёт через Google Play — выбрать окончательный (В3), потом его не поменять.
- Политика конфиденциальности по постоянной ссылке (почта в ней уже есть).
- `versionName 0.1.0`, `versionCode 1`; каждая следующая сборка — +1.
- Release-сборка с `isMinifyEnabled = true`: прогнать на эмуляторе, а не только debug.
- Резервная копия (В6) — решение до публикации, для тестов можно оставить выключенной.
