# Project XO — расчёт личного плана

Статус: черновик оркестратора 2026-11-09, ждёт утверждения владельца. Расчёт только для взрослых (18+). Все числа — ориентиры, не медицинские назначения. Формулы живут в одном модуле `core/plan` без `android.*`, покрыты тестами на граничные значения.

## Входные данные (шаг «О вас» в первом запуске)

| Поле | Диапазон | Примечание |
|---|---|---|
| Пол | мужской / женский / не указывать | Нужен только для формулы обмена. «Не указывать» = среднее двух формул |
| Возраст | 18–100 лет | Младше 18 план не считается: только вода и шаги без калорий |
| Рост | 120–230 см (или футы/дюймы) | |
| Вес | 30–300 кг (или фунты) | |
| Тренировок в неделю | 0, 1–2, 3–4, 5–6, 7+ | Любая целенаправленная нагрузка от 30 мин |
| Цель | снизить / держать / набрать | По умолчанию подсказывается по ИМТ, пользователь меняет |

## 1. Индекс массы тела (ИМТ)

`ИМТ = вес (кг) / рост (м)²`, одна цифра после запятой.

Категории ВОЗ для взрослых:

| ИМТ | Подпись в приложении |
|---|---|
| < 18,5 | Ниже нормы |
| 18,5–24,9 | Норма |
| 25,0–29,9 | Выше нормы |
| 30,0–34,9 | Ожирение I степени |
| 35,0–39,9 | Ожирение II степени |
| ≥ 40,0 | Ожирение III степени |

Под шкалой всегда подпись: «ИМТ — грубая оценка: он не различает мышцы и жир. Для спортсменов может быть завышен». Без цветов «опасности» и без слов «плохо», «лишний».

## 2. Обмен в покое (формула Миффлина — Сан Жеора, 1990)

- мужской: `10 × вес + 6,25 × рост − 5 × возраст + 5`
- женский: `10 × вес + 6,25 × рост − 5 × возраст − 161`
- не указывать: `… − 78` (среднее)

Почему эта формула: в систематическом обзоре Frankenfield и соавт. (2005) она чаще других укладывается в ±10 % от измеренного обмена и у людей с нормальным весом, и при ожирении.

## 3. Расход за день

`Расход = обмен × коэффициент активности`

| Тренировок в неделю | Коэффициент |
|---|---|
| 0 | 1,2 |
| 1–2 | 1,375 |
| 3–4 | 1,55 |
| 5–6 | 1,725 |
| 7+ | 1,9 |

## 4. Калории по цели

| Цель | Калории |
|---|---|
| Держать | расход |
| Снизить, ИМТ 25–29,9 | расход − 15 % |
| Снизить, ИМТ ≥ 30 | расход − 20 % |
| Снизить, ИМТ 18,5–24,9 | расход − 10 % |
| Набрать | расход + 10 % |

Нижняя граница: не меньше обмена в покое и не меньше 1 500 (м) / 1 200 (ж) / 1 350 (не указывать) ккал. Округление до 10 ккал.

При ИМТ < 18,5 цель «Снизить» недоступна, по умолчанию «Набрать», подпись: «Если вес снижается без причины, стоит показаться врачу».

Ожидаемый темп показываем примерно: `(расход − калории) × 7 / 7 700` кг в неделю, со знаком «≈».

## 5. Белки, жиры, углеводы

Расчётный вес: фактический, а при ИМТ > 25 — вес при ИМТ 25 (`25 × рост²`). Иначе белок у людей с большим весом выходит завышенным.

- **Белки:** г на кг расчётного веса: 0 тренировок 1,0; 1–2 — 1,2; 3–4 — 1,4; 5+ — 1,6. При цели «Снизить» +0,2. Не больше 35 % калорий. Ориентир: позиция ISSN (2017) 1,4–2,0 г/кг для тренирующихся, допустимый диапазон 10–35 % калорий.
- **Жиры:** 30 % калорий (в диапазоне 20–35 %), но не меньше 0,6 г/кг расчётного веса.
- **Углеводы:** остаток калорий / 4.

Округление до 5 г.

## 6. Вода

`30 мл × вес`, в пределах 1 500–3 500 мл, округление до 50 мл. Не меньше 1 600 мл (ж) / 2 000 мл (м): это питьевая часть нормы EFSA (2,0 / 2,5 л всей воды, из них около 20 % даёт еда). В дни тренировок подпись «+500 мл в день тренировки» (цель дня не меняется автоматически в v1).

## 7. Ходьба

По метаанализу Paluch и соавт. (Lancet Public Health, 2022): польза растёт до 8 000–10 000 шагов у людей младше 60 и до 6 000–8 000 у 60+.

- младше 60: 8 000 шагов;
- 60 и старше: 7 000 шагов.

## 8. Интервальное голодание

Предлагается только по желанию, режимы 12:12, 14:10, 16:8, 18:6 (часы без еды : окно еды). Начальный режим по умолчанию 12:12, окно 08:00–20:00. Приложение не определяет кетоз и не обещает медицинского эффекта.

Модуль не предлагается и выключен, если:
- возраст младше 18 (план не считается вообще);
- ИМТ < 18,5;
- пользователь отметил хотя бы одно: беременность или кормление грудью; расстройство пищевого поведения сейчас или в прошлом; диабет с инсулином или таблетками, снижающими сахар.

Формулировка вопроса нейтральная, ответ хранится только на телефоне. Если что-то отмечено: «Голодание не подойдёт без врача. Остальное приложение работает как обычно».
