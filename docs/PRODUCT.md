# Project XO — что делаем

Android-приложение для спокойного ежедневного учёта: вода, еда, ходьба. Ценность в том, что за две секунды видно, как идёт день, и за одно касание можно отметить стакан воды. Выглядит дорого за счёт точной анимации и типографики, а не за счёт эффектов.

Все решения уровня «курс проекта» живут в `CLAUDE.md`. Здесь они разложены в продуктовую спецификацию. Решения, которые тяжело отменить, и открытые вопросы находятся в `DECISIONS.md`.

## Для кого

Человек, который хочет следить за режимом без давления: без серий «не пропусти день», без красных цифр и стыдящих формулировок. Цели задаёт сам, любой модуль можно выключить.

## Принципы

1. Одно касание для самого частого действия (вода +250 мл, повтор шаблона еды).
2. Главный экран отвечает на один вопрос: «как мой день?». Ответ: одно кольцо с процентом.
3. Данные только на телефоне. Без аккаунтов, без сети в v1.
4. Доступность встроена с первого экрана: крупный текст, контраст, TalkBack, «меньше анимаций».
5. Никаких медицинских обещаний. Короткая пометка «не является медицинской рекомендацией» в еде и активности.

## Модули и волны

### Волна 1 (первая публикация)

| Модуль | Что умеет | Чего нет в v1 |
|---|---|---|
| Сегодня | Кольцо «Баланс дня» (рабочее название), под ним строки включённых модулей с прогрессом | Недельный итог |
| Вода | Быстрые порции (по умолчанию 250 мл), своя порция, список за день с отменой, цель в мл или унциях | Напитки с коэффициентами |
| Еда | Ручной ввод: название, ккал, белки, жиры, углеводы. Быстрые шаблоны. Список за день, цель по ккал | Поиск по базе, штрихкоды, фото |
| Ходьба | Шаги за день с датчика телефона, цель | Health Connect, история с часов |
| Напоминания | Мягкие, по желанию, с тихими часами | Умные напоминания |
| Виджет | Кольцо «Баланса дня» и кнопка «+250 мл» | Другие размеры виджета |

### Волна 2

Привычки, таймер голодания (без определения кетоза и медицинских обещаний), затем сон, вес, настроение. Дополнительно: недельный итог, экспорт в CSV, английский язык. Облако (Firebase) только в этой волне и только через тот же интерфейс репозитория.

## Навигация

Нижняя панель вкладок: «Сегодня», «Вода», «Еда», «Ходьба». Показываются только включённые модули. «Сегодня» всегда первая. Если включён один модуль, панели нет, есть только «Сегодня» и экран модуля. Настройки открываются из шапки «Сегодня».

## Первый запуск

1. **Заставка XO.** Логотип пишется, O работает как настоящий индикатор загрузки (см. `DESIGN.md`, раздел «Заставка 01»).
2. **Конфиденциальность.** Один экран простым языком: данные хранятся только на телефоне, никуда не отправляются, удаляются вместе с приложением. Ссылка на полную политику. Кнопка «Понятно».
3. **Настройка под себя.** Пять коротких шагов, любой можно пропустить, значения по умолчанию разумные:
   - модули: вода, еда, ходьба (переключатели, включены все);
   - цели только для включённых модулей (вода 2 000 мл, еда 2 000 ккал, шаги 8 000);
   - единицы: мл или унции, кг или фунты;
   - напоминания: выключены по умолчанию; если включены, задаются интервал и тихие часы (по умолчанию 22:00–8:00);
   - размер текста: как в системе, крупнее, ещё крупнее (с живым примером).
   Для ходьбы разрешение на распознавание активности запрашивается только здесь и только если модуль включён. При отказе показываем спокойное объяснение и кнопку в настройки, без повторных запросов.
4. **Сегодня.** Пустое первое состояние: кольцо 0 %, под ним строки модулей с подсказкой, как добавить первую запись.

Всё из пункта 3 потом меняется в настройках. «Сегодня» и «Баланс дня» считаются только по включённым модулям.

## Баланс дня

Одно число от 0 до 100 %, собранное из прогресса включённых модулей. Название и формула ещё не утверждены (`DECISIONS.md`, вопросы В1 и В2). До утверждения в коде используется рабочая формула из рекомендации В2, спрятанная за одной функцией, чтобы её можно было заменить в одном месте.

## Доступность

- Размер текста до 200 % без обрезки и наложений; кольцо и строки перестраиваются.
- Контраст текста не ниже 4,5:1 в обеих темах; режим «высокий контраст» усиливает приглушённые цвета и линии.
- TalkBack: кольцо читается как «Баланс дня, 72 процента»; каждая строка читается как «Вода, 1,6 из 2,4 литра».
- «Меньше анимаций»: системная настройка или своя в приложении; движение заменяется короткой сменой прозрачности.
- Цели без давления: «осталось 800 мл», а не «вы не выполнили».

## Готовность v1

- Сборка и тесты зелёные, запуск подтверждён записью с эмулятора.
- Анимации 60 кадров в секунду на телефоне среднего уровня.
- Нет захардкоженных цветов, размеров и строк.
- Пройден чек-лист `play-release`.
