# Чек-лист проверки перед выдачей тестировщикам

Проходить на эмуляторе (средний телефон, Android 10 и Android 15) и на одном реальном телефоне. Каждый пункт — скриншот или запись экрана.

## Первый запуск
- [ ] Полная заставка ~2,8 с, кольцо O переходит в кольцо «Баланс дня».
- [ ] Политика: короткая версия и полная по ссылке, почта varcolinz@gmail.com.
- [ ] Удобство: размер текста меняет текст сразу; контраст; «меньше анимаций»; выбор темы меняет весь экран.
- [ ] «О вас»: возраст 18–100, рост, вес; кг/фунты; удержание «+» листает быстро.
- [ ] План считается в конце, после анимации расчёта; «Назад» с плана ведёт к напоминаниям.
- [ ] После онбординга «Сегодня» показывает 0 %, все строки с нуля.

## Каждый день
- [ ] «+250 мл» на «Сегодня» и на экране воды; «Вернуть» отменяет.
- [ ] Еда: шаблон добавляет запись; своя запись считает калории из БЖУ; перебор — штриховка, без красного.
- [ ] Ходьба: шаги появляются после разрешения; без разрешения — понятный экран с кнопкой настроек.
- [ ] Ходьба вручную: «Добавить шаги вручную» → 3 500 → столбик в текущем часе, строка на «Сегодня»; «Отменить» снимает только эти шаги; перешли цель — анимация цели. На телефоне без датчика кнопка «Добавить шаги» сразу под сообщением.
- [ ] Android 9–10: шаги записываются без падения приложения.
- [ ] Шаги сами (Р67): после первого запуска приложение спрашивает «Физическую активность» → «Разрешить» → в шторке тихое «Шаги считаются». Закрыть приложение, пройти 100–200 шагов, открыть: шаги уже есть, число в уведомлении растёт. «Не считать шаги в фоне» убирает уведомление.
- [ ] Цель выполнена — анимация «Обход и шкала», вибрация.

## Календарь и история
- [ ] Нажатие на дату открывает календарь; выбранный день показывает итог и записи.
- [ ] Самочувствие, вес, заметка сохраняются и видны точкой в календаре.
- [ ] Дни до установки и будущие недоступны.

## Настройки
- [ ] Единицы меняют показ везде, данные не теряются.
- [ ] Выключить уведомления в Android — экран настроек это показывает.
- [ ] Тихие часы: напоминаний нет.
- [ ] «Удалить все данные» спрашивает подтверждение и стирает всё.

## Доступность и качество
- [ ] Крупный шрифт (системный 200 %): ничего не обрезано, кнопки не наезжают.
- [ ] TalkBack читает кольцо, строки модулей, кнопки.
- [ ] «Убрать анимации» в системе — анимаций нет, всё работает.
- [ ] Тёмная тема телефона и все 4 темы приложения: текст читается, нижняя панель без просвета.
- [ ] Поворот экрана и возврат из фона не теряют введённое.
- [ ] Перезагрузка телефона: шаги и данные на месте.
- [ ] Полночь: «Сегодня» переключается на новый день без перезапуска.

## Английский и тренировки (Р62)

- [ ] Настройки → Язык → English: все экраны на английском, на «Русский» возвращается, «По телефону» следует за Android.
- [ ] При английском: уведомления, виджет и названия заготовок привычек тоже на английском.
- [ ] Первый запуск с «Привычками»: после целей идёт шаг «Тренироваться дома?», «Включить тренировки» создаёт привычку «Тренировка».
- [ ] Планка: «Начать удержание» даёт отсчёт 3-2-1, кольцо заполняется, в конце вибрация и запись подхода; «Закончить подход» раньше записывает, сколько вышло.
- [ ] Отдых: кольцо убывает, «+30 с» удлиняет, «Пропустить отдых» работает.
- [ ] «Остановить» после первого подхода спрашивает подтверждение; без подходов выходит сразу.
- [ ] Профиль, «Итог недели»: числа сходятся с «Сегодня», без оценок и упрёков.
- [ ] Настройки → «Выгрузить данные»: файл CSV сохраняется, открывается в таблице, кириллица читается.
- [ ] Всё то же при системном шрифте 200 %.
- [ ] Настройки → Уведомления → «Итог недели» включается; «Показать пример напоминания» показывает значок XO в строке состояния.
